Round 4 — SR-4

  • SR-4Churn-warning terms → रीजाल्व · कनेक्शन · नेटवर्क (were resolve / customer / network)
  • SR-4Layout: churn-warning box ↔ ticket card swapped (warning on top, card above CTA)
Global — every screen Specific — this screen only
⚠️ Ticket ID display: if the ticket ID is long, either truncate it to 5 digits (e.g. #10482) or don’t show it at all. A long ID sitting in the top chip pulls attention away from the main education — the urgency/countdown on SR-3 and the churn warning on SR-4.
